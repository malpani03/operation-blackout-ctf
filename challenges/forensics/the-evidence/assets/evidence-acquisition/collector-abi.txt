Collector maintenance module: Linux x86-64, C ABI. Export r9_emit returns byte count or -1. Arguments: const uint8_t* profile, size_t profile_size, const char* asset, const uint8_t* share, size_t share_size, const uint8_t* prefix_bits, size_t prefix_size, uint8_t* rank_groups, size_t rank_capacity. Prefix buffer elements are individual bit values. Output storage capacity is measured in bytes. Runtime configuration selection and historian sequence acquisition are outside this module.
