Linux amd64 client ABI: maintenance_request(ctx, command, body, body_length, out) returns payload length. Context: session id[4], nonce[8], challenge[16], credential[32], next_sequence uint8. maintenance_response(ctx, payload, length) advances challenge and sequence. maintenance_continue(generation uint32, cursor[20], out[28]) prepares continuation. maintenance_journal(payload, length, out[20]) inspects a retained journal checkpoint while preserving its original reference. maintenance_cursor(scan, out[20]) obtains the normal current snapshot reference. maintenance_finish(ctx, device_key[32], transcript_digest[32], out[32]). Requests are framed by the acquisition host. maintenance.so is stripped; command formats are implemented in the client. The maintenance-client executable takes credential_hex as its sole argument, reads hexadecimal server frame lines from stdin and writes normal client frame lines to stdout; errors go to stderr.
